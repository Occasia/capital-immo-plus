# Phase 2: Smoke Test & Validation Campaign

This folder contains all the assets, copy, and scripts for the **Capital Immo Community** waitlist campaign. 

---

## Campaign Parameters

* **Community Name**: Capital Immo Community
* **Lead Goal**: 200–400 leads
* **Lead Target Metric**: Cost Per Lead (CPL) < $4.00 CAD (Targeting $1.50–$2.50)
* **Funnel Destination**: Waitlist Lead Form (Meta Instant Forms or simplified Landing Page)
* **Bilingual Focus**: English (EN) and French (FR) to capture the full Montreal/Laval target demographic.
